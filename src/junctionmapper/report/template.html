1. Quality control

{% if not n_fields %}

No fields were supplied, so there is nothing to report.

{% else %}

Cells found is every labelled cell. Measured excludes border-touching and degenerate (untraceable) cells. Isolated cells are measured but have no neighbour and so contribute no interfaces. With interfaces is the number of cells that actually contribute rows to the quantification. Reason columns can overlap, so they need not sum to the excluded total. Corner methods disagree counts cells where both corner methods found corners and reached different answers. All contacts filtered counts cells whose contacts were all too short to measure; the disagreement flag is deliberately not raised for these (the methods are not measuring the same thing), so check this column, not the disagreement one, for such cells. Multinucleate, anucleate and orphan nuclei are warnings rather than exclusions.
